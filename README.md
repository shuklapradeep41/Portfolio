# Sourab Kumar Shukla - Portfolio

A responsive, static portfolio website built for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository named `portfolio` (or any name you prefer).
2. Push these files to the repository's `main` branch.
3. In GitHub, open **Settings > Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. Your portfolio will be available at `https://YOUR-GITHUB-USERNAME.github.io/portfolio/`.

Before publishing, replace the LinkedIn URL in `index.html` if your public profile uses a different URL.
